- **`scripts/telemetry/` — commit attribution that does not depend on each agent volunteering its name.** On hive, 101 of 444 commits carry no `Co-Authored-By` trailer and 65 of those touch code, so any metric keyed on model silently drops ~15% of the corpus — biased toward whichever tool is quiet. Emitters (Claude Code hooks, a pi extension) append one JSON event per line to `${HIVESMITH_HOME:-~/.hivesmith}/telemetry/agent-events.jsonl`, and a `prepare-commit-msg` hook stamps an `Agent-Tool` trailer from the events inside the attribution window. The hook runs on every commit in every repo it is installed into, so it fails open: it never blocks a commit, never overwrites an existing trailer, and ignores events from another project or outside the window.
- **`scripts/harvest/` — read-only tools that measure what the git history already recorded.** No new telemetry required; both print a `RESULT:` line and never write to the repo they measure.
  - `plan_citations.py` — checks whether exec-plan code citations were true when written (94.1% on hive) and how far they have drifted against HEAD (63.9%). The 30-point gap is doc staleness, not dishonesty.
  - `correction_episodes.py` — attributes a fix to the work that caused it by blaming the lines the fix actually changes, rather than by file overlap (which attributes nearly every fix to nearly every feature on a corpus averaging 10.3 files per commit). Blame runs with `-C -C -C` so code movement does not absorb attribution, the denominator only counts origins inside the scanned window, and `--min-lines` drops incidental edits. Unattributable cases are reported (`additive-only`, `noise-only`, `unresolved`) rather than guessed, and the detection-bias caveat prints every run.
